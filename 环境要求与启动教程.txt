学生请销假系统 - 环境要求与启动教程
=====================================

一、环境要求
-----------

后端：
  - JDK 21（下载地址：https://adoptium.net/download/）
  - Maven 3.9+（下载地址：https://maven.apache.org/download.cgi）
  - MySQL 8.x（下载地址：https://dev.mysql.com/downloads/mysql/）

前端：
  - Node.js 18+（下载地址：https://nodejs.org/）


二、数据库初始化
---------------

1. 启动 MySQL 服务
2. 登录 MySQL 执行建库：

   CREATE DATABASE leave_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

3. 导入建表脚本：

   mysql -u root -p leave_system < backend/database/schema.sql


三、后端启动
-----------

1. 进入后端目录：

   cd backend

2. 修改数据库连接配置（如果与本机不一致）：

   编辑 src/main/resources/application.yml，修改 spring.datasource.url / username / password

3. 编译运行：

   mvn spring-boot:run

   或先打包再运行：

   mvn clean package -DskipTests
   java -jar target/leave-system-1.0.0.jar

4. 默认端口：8080
   默认管理员账号：admin / admin123


四、前端启动
-----------

1. 进入前端目录：

   cd frontend

2. 安装依赖：

   npm install

3. 启动开发服务器：

   npm run dev

4. 默认端口：5173，浏览器访问 http://localhost:5173
   前端开发服务器会自动将 /api 请求代理到后端 8080 端口


五、常见问题
-----------

Q: mvn 命令找不到？
A: 确认 Maven 已安装且配置了环境变量。或在 backend 目录下添加 Maven Wrapper（mvnw）。

Q: 数据库连接失败？
A: 检查 MySQL 服务是否启动，用户名密码是否正确，leave_system 库是否已创建。

Q: 前端 npm install 失败？
A: 尝试切换 npm 镜像：npm config set registry https://registry.npmmirror.com

Q: 端口被占用？
A: 后端 8080 端口修改 application.yml 中的 server.port
   前端 5173 端口修改 frontend/vite.config.js 中的 server.port
